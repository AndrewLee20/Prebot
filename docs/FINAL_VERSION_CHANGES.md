# Prebot Final Version

- 최종 버전 최초 실행 시 이전 테스트 주문번호와 주문목록을 1회 초기화합니다.
- 초기 상태의 주문번호 counter는 0이며 첫 신규 주문은 주문번호 1이 됩니다.
- 매일 로컬 시간 00:00에 주문번호 counter, 주문목록, current order를 자동 초기화합니다.
- 브라우저가 자정에 꺼져 있어도 다음 실행/주문 시 날짜 변경을 감지해 동일하게 초기화합니다.
- 장바구니(`prebot_cart`)는 자정 자동 초기화 대상이 아닙니다.
- 모든 신규 주문의 기본 상태는 `RECEIVED`(화면 표시: 주문 접수)입니다.
