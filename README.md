# Prebot
Gachon Univ P-Semester Project(P-CareerCatch2)

## Prebot Web — Stage 3

이번 단계 구현 범위:

- 모바일 프레임 고정 비율 개선
- 메뉴/장바구니 내부 스크롤
- 메뉴 옵션 → 실제 장바구니 상태 저장
- 장바구니 담기 완료 확인 모달
- "바로 주문" → 장바구니 이동
- "메뉴 더 담기" → 메뉴 화면 유지
- 장바구니 수량 증가/감소/삭제
- 총 주문금액 계산
- 주문하기 버튼 UI
